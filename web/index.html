论文诊断与优化

上传 PDF / Word → 需求确认 → 四维诊断 → 相似论文 → 段落改写 → 导出 Word / PDF。只做诊断、建议与局部改写，不代写整篇论文。

① 上传论文（PDF / Word）

支持 PDF 与 Word（.docx）文件（≤50MB；PDF ≤200 页）。扫描件需先 OCR 后再上传；Word 页码按字数估算；解析结果会持久化保存在本机 data/papers/。

论文层次、内容可实现性、正文格式、AI 率共四项。格式在本地检查；云端模型维度并行处理，本地模型依次执行。
