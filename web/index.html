上传 PDF → 需求确认 → 四维诊断 → 相似论文 → 段落改写 → 导出 Word。只做诊断、建议与局部改写，不代写整篇论文。

① 上传论文 PDF

仅支持 PDF 文件（≤50MB、≤200 页）。扫描件需先 OCR 后再上传；解析结果会持久化保存在本机 data/papers/。

诊断必须基于确认后的需求。修改需求会将已有诊断标记为过期，需要重新诊断。
