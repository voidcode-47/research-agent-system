# 论文诊断与优化工作台

本地运行的论文辅助工具：上传 PDF / Word 后完成需求确认、四维诊断、相似论文检索、段落级改写与 Word / PDF 导出，并提供参考文献调研与综合报告生成。

只做诊断、建议与局部改写，不代写整篇论文，不编造数据与引用。

## 功能

### 论文工作台（五步向导）

1. **上传 PDF / Word**：接受 `.pdf` 与 `.docx`，校验文件头与大小（≤50MB；PDF ≤200 页，Word 页码按字数估算）；旧版 `.doc` 与扫描版 PDF 会给出明确提示。上传解析显示实时进度，可随时取消且不保存半成品。
2. **需求确认**：根据论文标题、摘要与章节自动预填层次、格式与去 AI 味强度，核对后确认即可；确认后才能进入诊断。
3. **四维诊断**：论文层次、内容可实现性、正文格式、AI 率四个固定维度评分，并给出可执行修改建议；AI 率一栏支持中文与英文论文，检测理论起笔、段末套话、模糊归因、意义夸大、空泛强化词、长句堆叠等学术写作特征，并估算 AI 生成率。诊断过程显示实时进度条，可随时取消（已完成维度会保留）。AI 生成率基于规则估算，仅作自查参考。
4. **相似论文**：通过 Crossref / OpenAlex 检索相关文献，辅助判断选题重合度与创新点位置；检索过程显示进度并可取消，结果缓存 7 天。
5. **段落改写**：先基于全文生成全局改写方针（术语统一、跨段重复句式、章节过渡），再选择正文段落按去 AI 味 / 学术化 / 精简等模式套用该方针改写，展示差异后可逐段采纳。支持勾选多个正文段落批量改写（单次最多 8 段），批量与单段改写均显示进度、可取消，完成后逐段查看差异并采纳。
6. **导出**：保留标题层级与正文结构，可导出可编辑 `.docx`、`.pdf`（本机中文字体嵌入）或《论文修改说明》`.docx`（诊断结论、问题清单与逐段前后对照）。文件名沿用原论文名，默认推荐与上传格式一致的导出格式。

再次打开工作台时，会自动恢复上次查看的论文与步骤，无需重新选择。

### 参考文献调研

- 输入论文方向 → 并行检索 Crossref / OpenAlex → 按相关度去重排序展示文献。
- 基于文献题录与摘要生成结构化调研报告（背景、现状、方法、实验、争议与建议），自动附参考文献列表。
- 实时进度条与阶段日志，可随时停止调研；完成后支持追问、下载 Markdown / Word、历史报告管理。

### 设置

- 全站使用同一个模型：在「模型提供商」中填写 Key / Base URL 后立即生效。
- 支持 DeepSeek / 智谱 / 通义 / 自定义 OpenAI 兼容 API / Ollama / LM Studio。
- API Key 只写入本地 `.env`，不回传前端、不进入仓库。

## 快速开始

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
python server.py
```

浏览器访问 <http://localhost:8501>。也可双击 `start.bat` 启动。

首次使用请在「设置 → 模型提供商」中配置至少一个模型服务并测试连接。

### 管理员账号

- 左侧边栏「管理员登录」可登录；管理员可修改模型配置，且不受每日调用额度限制。
- 普通用户只能使用管理员设定的模型，设置页为只读。
- 首次启动会自动生成随机密码，保存在本机 `data/admin_credentials.txt`；登录后请妥善保存并删除该文件。
- 登录状态保存在 `data/admin_sessions.json`（仅存令牌哈希），有效 7 天，重启服务不会掉线。
- 也可在 `.env` 中设置 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 指定账号（优先级高于本地文件）。

## 项目结构

```
server.py              FastAPI 入口、文献调研与报告接口
api/paper.py           论文工作台 API（上传/诊断/相似/改写/导出）
paper/                 PDF / Word 解析、持久化、诊断、改写、导出
rules/                 格式规则与去 AI 味规则引擎
config/                全局配置、论文 schema、提示词
llm/                   统一 LLM 工厂与 OpenAI 兼容实现
tools/academic_search   Crossref / OpenAlex 检索
utils/                 偏好、配额、guard、日志、Markdown→Word
web/                   原生 HTML/JS SPA（无框架）
data/                  本地数据（论文、报告、偏好；已 gitignore）
```

## 数据与隐私

- 论文 PDF、诊断结果、改写记录与报告均保存在本地 `data/`，不会上传到第三方服务（模型推理请求除外）。
- 调用云端模型时，仅发送当前任务所需的文本片段；论文正文以 `<paper_text>` 数据块包裹，明确与指令隔离。
- `.env`、`data/papers/`、`data/reports/`、`data/ui_prefs.json`、`data/quota.json` 均已 gitignore。
- 审计日志不记录论文正文。
